# ちゃっと投票 ChatVote

Delta Chatのチャット内で、議題と記名投票を共有するアプリです。賛成・反対・保留と、任意の意見を送れます。

## 配布ファイル

- `ChatVote-1.3.0.xdc`：Delta Chatで共有して使うアプリ。
- `index-demo.html`：ブラウザ単体で試すデモ。通信せず、再読み込みで初期化します。
- `index.html`：画面模式図付きの操作手順。

内部manifestのversionと配布ファイル名を `1.3.0` に統一しています。修正のたびに内部版を更新し、XDCファイル名と配布一式ZIPにも同じ番号を使用します。

## 使い始める

1. Delta Chatで、参加者とのチャットに `ChatVote-1.3.0.xdc` を添付して送ります。
2. 全員が同じ添付アプリを開きます。別々に送り直すと別の投票になります。
3. 「議題を作成」または「＋」で議題を発信します。
4. 議題を選び、賛成・反対・保留を選択し、必要なら意見を書いて「投票を送信」を押します。
5. 集計と意見一覧で反映を確認します。変更時は「投票を更新」を押します。

連続送信の待ち時間が出た場合は、表示された秒数を待ち、再操作してください。

## 送信した議題のキャンセル

自分が作成した議題を開き「議題をキャンセル」を押し、確認画面で承認します。管理モードは不要です。参加者にもキャンセル済みと表示され、その後の投票を止めます。既存の投票と意見は参考として残り、再開はできません。内容を訂正する場合は新しい議題を作成してください。

議題作成画面は、色付き背景と濃い入力枠、必須表示、入力中の強調を備えています。

## 管理操作

管理モードに入ると、他の参加者が投稿したものを含む全員の議題を締切・再開・削除できます。初期パスワードは `secret` です。管理ボタンは初期設定で1回タップします。削除前に議題名と作成者を確認してください。作成者や投票者の記録は、管理者のものへ置き換えません。

管理設定とパスワード変更は画面のセッション内のみ有効です。開き直すと初期設定へ戻ります。共有認証ではありません。期限後に「再開」しても期限は変更されません。本文編集と削除の取り消し機能はありません。

管理パスワードを知る参加者が管理モードに入る方式です。これは操作ロックであり、管理者の本人認証ではありません。受信側は管理操作の申告を受け入れ、改造アプリによる不正な管理命令までは防げません。厳密な権限管理が必要な用途には別の認証設計が必要です。1.3.0での管理命令に対応するため、参加者全員が同じ新版XDCを使用してください。

## 通信とデータ

議題と投票をwebxdc更新履歴で共有し、起動時に履歴を再生します。同じ利用者の投票変更は1票として集計します。通信はDelta Chatに依存し、圏外の間は相手端末に届きません。通信再開後に結果を確認してください。Bluetooth / Wi-Fi Direct同期は実装していません。

送信依頼や自端末への反映は、相手への配達完了を保証しません。チャットへの送信権限がない場合も共有できません。投票専用サーバーやTinyboxはアプリの必須要件ではありません。

記名式のため参加者に名前・選択肢・意見が見えます。CSV出力にも個人名と意見を含みます。議題削除はアプリ表示からの削除であり、更新履歴・CSV・他者の控えの完全消去ではありません。

## 検証状況と利用範囲

模擬APIで、2人の投票、同時操作、受信順序逆転、重複受信、投票変更、作成者の管理制御、締切・再開、履歴復元、削除、送信失敗、デモ動作を確認しています。実端末間の通信、圏外復帰、CSV保存、全画面操作は未確認です。本番導入前に2台で検証してください。

受信payloadの利用者IDを偽装する改造アプリまで防ぐ仕組みはありません。期限判定は送信端末の時計に依存します。厳密な本人確認・秘密投票・選挙管理が必要な用途は別途評価してください。

## ソースと保守

`chatvote/index.html` にUIと同期処理を同梱しています。`chatvote/sync.js` は同期処理の参照用ソースです。`webxdc.js` はDelta Chatが実行時に提供します。通常ブラウザではwebxdc APIがない場合にデモになります。

アプリ固有の不具合対応・動作確認は引き続き必要です。利用するライブラリのライセンスと配布条件は、再配布前に確認してください。

仕様：https://webxdc.org/docs/spec/sendUpdate.html ／ https://webxdc.org/docs/spec/setUpdateListener.html

## 版を変えるときのデータ引継ぎ

内部版1.2.0以降は画面上部の「データ引継ぎ・バックアップ」からJSONを書き出し、新版で読み込んで参加者と共有できます。別のXDCへ自動で履歴は移りません。移行後は各参加者が「以前の自分の記録」を選択します。旧版に書き出しボタンがない場合の補助スクリプトと注意点は、同梱の「データ引継ぎ手順.md」を参照してください。

## 配色と表示版の確認

この配布版は 1.3.0 です。アプリのヘッダーに版番号を表示します。明るい配色を使用し、議題一覧・本文・投票・意見・管理・入力画面の文字色と背景色を明示しています。無効なボタンやグラフの文字も読める配色を指定しています。古い添付アプリは自動で更新されないため、新しいXDCを開いたことをヘッダーの版番号で確認してください。

配色は実際の画面生成コードの19状態をスマホ幅390pxとPC幅1024pxで検査し、3,461か所の文字についてコントラスト比4.5対1以上を確認しました。これは仮想画面ツリーでの検査であり、iPhone実機、実際のチャート描画、OSによる画面反転は未確認です。
